# 開場旁白稿（溢灑站；由 _gen_audio.py 讀取產音檔）

> 格式：`## 檔名代號｜用途` 之後到下一個 `## ` 前的段落＝旁白文字（多行會併成一段）。
> 改完文字重跑 `_gen_audio.py`，只會重產有改動的檔。內容只講院內〈化療藥品溢灑處理〉技術評核表單內的事。

## intro_home｜首頁開場旁白
歡迎來到化療藥品溢灑處理教材。這套教材依照院內溢灑處理技術評核表單設計，從第一時間尋求協助、設置警戒區、穿戴防護裝備、清理環境、卸除防護裝備，到紀錄通報與暴露處置。每一題先選答案，再聽講解。

## intro_handson｜③ 動手互動情境開場旁白
情境開始。病室走道的地上，有化療藥品灑出來了，你是第一個到達現場的人。接下來每一步，都由你決定怎麼做：先求援、管制走動，再圍警戒區、清理環境，最後依順序卸除防護裝備。選錯了，會看到後果，再試一次。
